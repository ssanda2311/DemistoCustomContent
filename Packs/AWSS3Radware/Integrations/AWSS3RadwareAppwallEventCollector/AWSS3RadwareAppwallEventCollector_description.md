This is the AWS S3 Radware Appwall event collector integration for XSIAM.

This is the default integration for this content pack when configured by the Data Onboarder in Cortex XSIAM.

## Configure AWS S3 Radware Appwall Event Collector on Cortex:
1. Navigate to **Settings** > **Configurations** > **Automation & Feed Integrations**.
2. Search for AWS S3 Radware Appwall Event Collector.
3. Click **Add instance** to create and configure a new integration instance.

    | **Parameter** | **Required** |
    | --- | --- |
    | Queue URL                  | True |
    | Access Key ID              | True |
    | Secret Access Key          | True |
    | AWS Region                 | True |
    | Vendor Name                | True |
    | Product Name               | True |


4. Click **Test** to validate the URLs, token, and connection
